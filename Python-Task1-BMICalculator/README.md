
# 🧮 BMI Calculator

## 📌 Project Description

The BMI Calculator is a simple Python application that calculates a person's Body Mass Index (BMI) using their height and weight. It also classifies the BMI into different health categories.

---

## 🚀 Features

- Accepts user weight (kg)
- Accepts user height (meters)
- Calculates BMI
- Displays BMI up to 2 decimal places
- Shows BMI Category
- Handles invalid input
- Checks for zero or negative values
