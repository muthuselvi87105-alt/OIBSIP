# 🌦️ Weather App

## 📌 Project Description

The Weather App is a Python application that provides real-time weather information for any city using the OpenWeatherMap API. Users can enter a city name to view the current temperature, humidity, and weather conditions.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Display humidity
- ☁️ Display weather description
- 📍 Display city name
- 🔗 Fetch live weather data using OpenWeatherMap API
- ❌ Handle invalid city names
- ⚠️ Handle API and network errors

---

## 🛠️ Technologies Used

- Python
- Requests Library
- OpenWeatherMap API

## 🔑 API Key

This project uses the **OpenWeatherMap API**.

1. Create a free account on OpenWeatherMap.
2. Generate an API key.
3. Replace the API key in the Python code:

```python
api_key = "YOUR_API_KEY"
```
